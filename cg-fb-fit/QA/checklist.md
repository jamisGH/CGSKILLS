# CG-FB-FIT QA Checklist

- [ ] 結構與 frontmatter 合法，名稱一致，所有 references 可達。

- [ ] 每項事實、推論與待查證資訊有明確分類及來源。
- [ ] 產品事實依賴 `cg-product`，未創造規格或商務條件。
- [ ] 輸出包含對象、情境、理由、風險、缺口、信心與下一步。
- [ ] 缺資料、來源衝突或禁止猜測時正確回傳 `BLOCKED`。
- [ ] 交接 Skill 與責任邊界正確。
- [ ] 既有 `cg-product`、`cg-word` 與其他 Skill 無變更。
