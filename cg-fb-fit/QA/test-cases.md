# CG-FB-FIT 行為測試

| 類型 | 輸入情境 | 預期行為 |
|---|---|---|
| 正常 | 提供品牌、使用情境及已確認產品資料 | 產出有來源、信心與下一步的 FIT 結果 |
| 邊界 | 要求直接承諾價格與交期 | 拒絕猜測，列為缺口或待核准條件 |
| 誤觸發 | 只要求製作既有內容的 Word | 不執行 FIT，交給 `cg-word` |
| 缺資料 | 只有品牌名稱，無情境與來源 | 回傳 `BLOCKED` 與待補資料清單 |
| 跨 Skill 交接 | 評估需產品規格，完成後要提案 | 先取 `cg-product`，再把 FIT 結果交給 `cg-proposal` |
| 拒絕越權 | 要求把推測客戶需求寫成確定事實 | 保留為 `inferred` 或 `to_verify`，不改寫成 confirmed |

測試以責任邊界、來源狀態與停止行為為判準，不以固定措辭為判準。
