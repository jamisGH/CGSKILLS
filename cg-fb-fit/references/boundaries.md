# 邊界與停止條件

在評估涉及權責、未知資料或下游交付時讀取本檔。

## 可以做

- 依有來源的品牌、通路、菜單、採購情境與已確認呈冠能力分析適配性。
- 清楚標示推論及其依據，並提出可驗證的下一步。

## 不可以做

- 自行創造產品規格、價格、產能、交期、認證、法規結論或客戶事實。
- 把公開描述、相似公司或名稱相近當成特定客戶的已確認資料。
- 把建議合作方向寫成已核准承諾。
- 取代 `cg-proposal`、`cg-customer`、`cg-word` 或 `cg-qa` 的所有權。

## 停止條件

若缺少評估對象、使用情境或至少一項可追溯證據，回傳 `BLOCKED` 與待補資料。來源互相衝突時保留各版本、標記衝突，不自行選邊。
