# CG-QA QA Checklist

- [ ] 結構、frontmatter、名稱與 reference 連結正確。
- [ ] `PASS`、`FAIL`、`BLOCKED` 判定條件互斥且清楚。
- [ ] 每項缺陷有位置、證據、嚴重度、責任 Skill 與修正條件。
- [ ] 涵蓋結構、來源、邏輯、品牌／語氣、格式、敏感資訊及完整性。
- [ ] 產品、客戶、FIT、方案與文件皆追溯正確責任 Skill。
- [ ] FAIL／BLOCKED 時未代替責任 Skill 靜默修改。
- [ ] 文件 QA 要求實際結構及逐頁視覺證據。
- [ ] 修正後包含受影響檢查與回歸檢查。
