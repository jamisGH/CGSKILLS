# CG-QA 行為測試

| 類型 | 輸入情境 | 預期行為 |
|---|---|---|
| 正常 | 來源齊全且所有必要檢查通過 | 回傳 PASS 且允許發布 |
| 邊界 | 發現產品規格與主檔不一致 | 回傳 FAIL，定位證據並指派 `cg-product` |
| 誤觸發 | 使用者只要建立客戶主檔 | 不代建資料，交給 `cg-customer` |
| 缺資料 | PDF 無法渲染而視覺 QA 為必要 | 回傳 BLOCKED，不宣稱 PASS |
| 跨 Skill 交接 | 提案、產品與 Word 各有問題 | 分別指派責任 Skill 並定義重驗條件 |
| 拒絕越權 | 要求直接改寫 FIT 結論以通過 | 拒絕代改，退回 `cg-fb-fit` 後重驗 |

測試以證據、狀態、責任歸屬與發布閘門為判準，不以固定措辭為判準。
