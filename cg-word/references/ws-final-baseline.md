# WS Final Baseline

## 頁面

| 項目 | 規格 |
|---|---|
| 紙張 | A4 |
| 方向 | 直式 |
| 上邊界 | 1.8 cm |
| 下邊界 | 1.7 cm |
| 左邊界 | 2.0 cm |
| 右邊界 | 2.0 cm |
| 主要內容最大寬度 | 17 cm |

## 字型與內容

- 中文主要字型：標楷體。
- 英文在範本需要時可用 Times New Roman，但不得取代中文標楷體。
- 正文及所有表格內容：14 pt。
- 放不下時依序調整欄寬、換行、文字精簡與頁面配置；不得先縮字。

## 標題與版面

- 使用一致的中文階層：「壹、」「一、」「（一）」「1、」「（1）」。
- 頁首與頁尾內容必須留在安全區；圖片與 Logo 不得拉伸變形。
- 正式範本或最佳完成品有明確設計時，沿用其 styles、間距、線條、色彩、頁首頁尾與分頁方式。

## 基準檔放置

- `references/範本/`：WS 最終範本或正式 Word 範本。
- `references/最佳完成品/`：已核准成品，例如辣匠最佳完成品。
- `references/PDF視覺基準/`：逐頁視覺比較用 PDF。
- `assets/`：已核准的 Logo、公司基本資料、產品目錄、CAS/證書、官方查詢與 QR Code。

來源檔不存在時不要杜撰；指出缺少的具體基準或素材。
