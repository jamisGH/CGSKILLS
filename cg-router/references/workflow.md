# 路由與複合流程

需要選擇 Skill、排定跨 Skill 順序或處理 BLOCKED 時讀取本檔。

## 標準複合流程

```text
cg-customer（客戶資料確認）
  -> cg-product（產品事實確認）
  -> cg-fb-fit（適配評估）
  -> cg-proposal（提案內容）
  -> cg-word（僅需 Word/PDF 時）
  -> cg-qa（最終驗收）
```

這不是固定全跑清單。單純查產品只用 `cg-product`；既有已確認內容轉 Word 可直接用 `cg-word`；只做驗收直接用 `cg-qa`。

## 意圖處理

- 單一意圖：選一個主要 Skill，只加入不可缺少的事實來源。
- 複合意圖：依資料依賴排序，逐步保存狀態與來源。
- 模糊意圖：以交付物判定；交付物也不明時詢問一個最關鍵問題。
- 缺資料：能安全補自既有可信來源則路由查核，否則列出缺口。
- 上游 BLOCKED：停止依賴步驟，回報阻塞來源、受影響下游與解除條件。
