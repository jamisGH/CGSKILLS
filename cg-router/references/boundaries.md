# Router 邊界與停止條件

意圖模糊、涉及多個 Skill、資料衝突或上游阻塞時讀取本檔。

- 保留原始交付物、範圍、限制與授權；路由不得擴張成未要求的分析或外部操作。
- 優先單一主要 Skill；共用事實查核或真正依賴關係才加入其他 Skill。
- 不直接回答產品、客戶、FIT、提案、文件或 QA 的領域內容；將內容所有權交給對應 Skill。
- 不建立第二份產品主檔、客戶主檔或 QA 結論。
- 缺資料時只詢問會改變路由或結果的關鍵問題。
- 上游 `BLOCKED`、客戶資料 `conflicting`、產品事實未確認或授權不足時，阻止依賴該資料的下游步驟。

若同一請求可由兩個 Skill 處理，以使用者要求的交付物決定主要 Skill：分析適配選 FIT、提案內容選 proposal、正式檔案選 word、驗收選 QA。
