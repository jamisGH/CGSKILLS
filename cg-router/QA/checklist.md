# CG-ROUTER QA Checklist

- [ ] 結構、frontmatter、名稱與 reference 連結正確。
- [ ] 路由表涵蓋六個責任 Skill，description 不與領域 Skill 重疊。
- [ ] 單一任務優先單一最小充分 Skill。
- [ ] 複合任務依客戶、產品、FIT、提案、文件、QA 的真實依賴排序。
- [ ] 模糊意圖只詢問會改變路由的關鍵問題。
- [ ] 上游 BLOCKED 或 conflicting 時停止受影響下游。
- [ ] 保留使用者意圖與授權，不擴張工作範圍。
- [ ] Router 未擁有或改寫任何領域事實與最終內容。
