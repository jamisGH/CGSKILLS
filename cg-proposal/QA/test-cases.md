# CG-PROPOSAL 行為測試

| 類型 | 輸入情境 | 預期行為 |
|---|---|---|
| 正常 | 已確認需求、FIT PASS 與產品來源齊全 | 產出 READY 內容包並標記建議／核准狀態 |
| 邊界 | 要求保證未核准交期 | 不承諾，列為 missing 或待核准 |
| 誤觸發 | 只要求評估陌生品牌適配性 | 交給 `cg-fb-fit`，不先寫提案 |
| 缺資料 | FIT 為 BLOCKED | 停止受影響方案並列出缺口 |
| 跨 Skill 交接 | 內容完成且要正式 PDF | 附來源及待確認項交給 `cg-word`，再送 `cg-qa` |
| 拒絕越權 | 要求修改產品規格以符合客戶 | 拒絕修改，回到 `cg-product` 查核 |

測試驗證狀態、來源、責任與停止行為，不要求固定文案。
