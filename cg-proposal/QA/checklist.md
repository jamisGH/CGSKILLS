# CG-PROPOSAL QA Checklist

- [ ] 結構、frontmatter、名稱及 reference 連結正確。
- [ ] 觸發限於方案、提案架構與銷售內容，不誤接 FIT、主檔或排版。
- [ ] 客戶需求、FIT 結果與產品事實均有來源及狀態。
- [ ] FIT 缺失或 `BLOCKED` 時未繼續作肯定承諾。
- [ ] `recommended` 與 `approved` 明確分開。
- [ ] 未猜測價格、產能、交期、法規或食品安全資訊。
- [ ] 與 `cg-fb-fit`、`cg-product`、`cg-customer`、`cg-word`、`cg-qa` 交接清楚。
- [ ] 既有 Skill 無變更。
