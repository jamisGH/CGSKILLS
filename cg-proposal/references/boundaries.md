# 邊界與停止條件

在提案含商務條件、來源缺口或跨 Skill 交接時讀取本檔。

- 不自行產生價格、折扣、MOQ、產能、交期、獨家權、法規或食品安全結論。
- 不把建議、假設、草案或待核准條件描述成已承諾。
- 不從客戶名稱推測需求；客戶正式欄位由 `cg-customer` 提供。
- 不改寫 `cg-product` 主資料或 `cg-fb-fit` 結論以迎合方案。
- 不負責 DOCX/PDF 排版；只交付已確認內容與結構給 `cg-word`。

缺少關鍵需求、有效 FIT 結果或必要產品事實時回傳 `BLOCKED`。來源衝突時列出衝突與責任 Skill，不自行選用較有利版本。
