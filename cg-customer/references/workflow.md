# 客戶資料工作流程

建立、更新、查核、搜尋重複或提供下游資料時讀取本檔。

1. 記錄操作目的與允許使用的來源。
2. 正規化文字與聯絡格式，但保留原始值及來源；不把格式化視為驗證。
3. 欄位狀態：正式來源一致為 `verified`；僅單一未核准來源為 `unverified`；可信來源互斥為 `conflicting`；無值為 `missing`。
4. 重複候選依穩定識別碼、正式登記資訊、網域、地址與授權聯絡資料綜合判定，並列出支持與反對證據。
5. 只有證據足以確認同一實體且操作獲授權才可提出合併；保留來源、歷史與衝突，不靜默丟值。
6. 回傳下游時只提供必要欄位、狀態、來源、更新日期及使用限制。
