# CG-CUSTOMER QA Checklist

- [ ] 結構、frontmatter、名稱與 reference 連結正確。
- [ ] 唯一識別、正式名稱、別名、聯絡、來源、狀態、更新時間與敏感度欄位齊全。
- [ ] `verified`、`unverified`、`conflicting`、`missing` 使用一致。
- [ ] 正規化未被誤當驗證，欄位均可追溯來源。
- [ ] 重複／合併判定有多面向證據，無靜默覆蓋或資料遺失。
- [ ] 個資與商務敏感資訊符合最小揭露及授權範圍。
- [ ] 下游引用包含值、狀態、來源與更新日期。
- [ ] 未越權做 FIT、提案、產品主資料或排版。
